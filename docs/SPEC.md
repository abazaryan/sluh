# Спецификация: «Слух»

## Проблема

В Anki нет режима, где отвечаешь голосом, и нужно вручную нажимать одну из четырёх кнопок оценки после каждой карточки. Пользователь (уровень французского A2) хочет тренировать устное воспроизведение и получать оценку автоматически.

## Цель

Приложение интервальных повторений, где:
1. Пользователь видит или слышит подсказку и отвечает по-французски голосом (или текстом, если говорить нельзя).
2. Ответ сверяется с эталоном.
3. Оценка выставляется автоматически по точности и скорости; пользователь может поправить её одним касанием.
4. Колоды импортируются из APKG (их пользователь получает от ИИ вместе с аудио от Gemini TTS).

## Факты, предположения, открытые вопросы

**Факты**
- Устройства: Android + Chrome (основное), Windows + Edge.
- Оба браузера поддерживают `webkitSpeechRecognition`. Распознавание идёт через облачную службу браузера и требует интернета.
- Во встроенном окне claude.ai микрофон не запустился.

**Предположения (нужно проверить)**
- Web Speech API распознаёт французский пользователя на уровне A2 достаточно точно для сверки по словам.
- Время до начала речи — полезный сигнал трудности карточки.
- APKG, которые делает ИИ, — в «старом» формате (`collection.anki2` или `collection.anki21`), а не в новом `collection.anki21b` (сжатие zstd).

**Открытые вопросы**
- Какие типы карточек нужны помимо «русский → французский вслух»? (например, «услышал французский → повтори», «услышал → переведи»).
- Нужна ли синхронизация между телефоном и ноутбуком?

## Этапы

### Этап 1. Перенос прототипа и публикация (go / no-go по распознаванию)
- Проект на Vite + TypeScript + React со структурой `src/core`, `src/platform`, `src/ui`.
- Перенести функциональность `prototype/sluh.html` без потери возможностей: сверка, замер времени, предложение оценки, ручная коррекция, ввод текстом, «Не знаю», журнал с копированием в JSON, настройки, встроенная колода примеров, диагностика (поддержка распознавания, разрешение микрофона, кнопка «Проверить микрофон»), защита от зависания микрофона (5 с).
- Юнит-тесты для сверки и оценки (минимум: апострофы и элизия, акценты, лишние и пропущенные слова, пустой ответ, пороги времени, поправка на длину фразы).
- Публикация на GitHub Pages через GitHub Actions.

**Критерии приёмки**
- `npm test` и `npm run build` проходят.
- По HTTPS-ссылке на Android Chrome микрофон запускается, ответ распознаётся, журнал копируется.
- Пользователь проходит 11 карточек и присылает журнал для калибровки порогов.

### Этап 2. Импорт APKG
- Чтение `.apkg`: ZIP → `collection.anki2` / `collection.anki21` через sql.js, файл `media` (соответствие номеров и имён) и сами медиафайлы.
- Извлечение полей заметок, выбор пользователем, какое поле — подсказка, какое — ответ, какое — аудио (`[sound:...]`).
- Для `collection.anki21b` — понятное сообщение, что формат пока не поддерживается.
- Хранение колод, карточек и аудио в IndexedDB.
- Тесты на разбор с небольшим тестовым APKG (создать фикстуру).

### Этап 3. Планировщик FSRS
- `ts-fsrs` с оценками 1–4. Очередь «к повторению сегодня», новые карточки с дневным лимитом.
- Хранение состояния карточек и истории повторений.
- Окончательная оценка — та, что подтвердил пользователь (автоматическая или исправленная).

### Этап 4. Офлайн и аудио
- PWA: установка на главный экран, работа офлайн для повторения (распознавание всё равно требует сети; в офлайне — только ввод текстом).
- Проигрывание аудио карточки из APKG; встроенный синтез — только если аудио нет.

### Этап 5 (по решению пользователя). Улучшенное распознавание
- Серверный прокси для распознавания через внешний API (например, Gemini) без ключей в клиенте.
- Только если по данным этапа 1 встроенного распознавания недостаточно.

## Правило оценки (начальная версия)

- Точность = 1 − (расстояние Левенштейна по словам) / max(длина эталона, длина ответа).
- Точность < 60 % → Снова.
- Иначе по времени до начала речи: ≤ 2,5 с → Легко; ≤ 6 с → Хорошо; дольше → Трудно. К порогам +0,3 с за каждое слово сверх 4.
- Если точность < 85 %, оценка не выше «Трудно».
- Все пороги настраиваются и будут откалиброваны по журналу.
